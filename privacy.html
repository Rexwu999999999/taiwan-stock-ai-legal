Taiwan Stock AI Threads 隱私權政策

最後更新日期：2026 年 10 月 10 日

一、服務目的

Taiwan Stock AI Threads 是用於台灣股票產業題材研究的資料分析工具。 本工具計畫使用 Meta Threads API 搜尋與分析產業相關討論， 觀察題材熱度及其歷史變化。 本工具不提供證券交易執行服務。

二、資料蒐集

在取得適當 API 權限後，本工具可能處理下列資料：

  • Threads 公開貼文的文字內容。
  • 貼文發布時間及相關題材分類。
  • 必要的貼文識別資訊，用於資料去重與歷史分析。
  • 經授權帳號提供的必要 API 存取資訊。

如研究需要辨識重複作者，可能使用去識別化的作者代碼。 此類處理不代表資料已達到完全匿名。

三、資料使用方式

蒐集的資料僅用於產業題材分類、討論熱度統計、 歷史趨勢研究及資料品質驗證。 不會使用 Threads API 代替使用者發布貼文。

四、資料保存與安全

API 存取憑證應存放於受限制的環境變數或秘密管理設定， 不會公開於程式碼儲存庫。 研究資料將依實際研究需要保存，並採取適當存取控制。 當資料不再需要或平台政策要求刪除時，將進行清理。

五、第三方平台

本工具使用 Meta 提供的 Threads API。 Threads 平台上的資料處理亦受 Meta 相關政策約束。 本工具會依適用的 API 條款及資料使用限制處理相關資訊。

六、資料查詢與刪除

如需詢問資料處理方式，或提出與本工具保存資料相關的刪除請求， 請透過下列聯絡方式提出。 收到請求後，將確認相關資料是否由本工具持有， 並依適用規定處理。
